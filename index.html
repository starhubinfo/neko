Neko Support

Neko is a cozy proxy companion for iOS — a friendly front end for the meow-rs kernel (compatible with mihomo / Clash Meta). This page covers setup, common questions and troubleshooting.

Getting started

Three steps to connect

  1. Add a Feed Open the Feeds tab and tap Add a Feed. Paste a subscription URL, or paste one or more node links directly. Neko fetches the subscription and fills your node list.
  2. Pick a node Go to the Nodes tab. Tap Sniff to measure latency, then choose a node in the Pick a Kitty group — or let Auto Sniff select the fastest one for you.
  3. Tap Connect Back on Home, tap Connect (or tap Neko). The first time, iOS asks for permission to add a VPN configuration — you must allow it for the tunnel to start.
Neko does not provide proxy servers. You bring your own subscription or node details from a provider you trust, or from your own server.

What Neko supports

AreaSupported
Node protocols Shadowsocks (SS), VMess, Trojan, VLESS, Hysteria2
Subscription formats Base64-encoded link lists, plain link lists, and Clash / mihomo YAML configs
Routing modes Smart Paw (rule-based) · Roam Free (global) · Stay Home (direct)
Node groups Auto Sniff picks the lowest-latency node automatically · Pick a Kitty lets you choose manually
Platform iPhone and iPad. The tunnel requires a real device — VPN tunnels do not route traffic in the iOS Simulator.

The cat tells you the state

Neko's mascot mirrors the tunnel, so you never have to read a status line: asleep means disconnected, alert means connecting, happy means connected, and zooming means traffic is flying.

Troubleshooting

Common questions

“No supported nodes were found in this subscription”

Neko could read the subscription but found no nodes it can parse. Usually one of:

  • The links use a protocol Neko does not support yet (for example ssr://, tuic:// or hysteria:// v1). Neko supports SS, VMess, Trojan, VLESS and Hysteria2.
  • The URL returned an error page or an empty body instead of a subscription.
  • The link was truncated when copied — paste the entire link, including everything after ? and #.

Open the Prints tab right after the failure: Neko logs the protocol scheme it saw, which tells you exactly what the input contained.

Tapping Connect does nothing, or no VPN prompt appears
  • Make sure you have at least one node — with an empty node list Neko refuses to connect and asks you to add a subscription first.
  • The first connection needs your permission to install a VPN configuration. If you dismissed the prompt, try again and choose Allow.
  • If you previously denied it, check Settings → General → VPN & Device Management on your device and remove any stale Neko profile, then reconnect.
The VPN connects but I have no internet
  • Check the node itself: run Sniff in the Nodes tab. If a node times out, it is unreachable from your network — pick another one.
  • Confirm your subscription is still valid and has data remaining (see the usage bar in Feeds).
  • Try switching routing mode to Roam Free (global) to rule out a rule-matching problem.
  • Disconnect and reconnect after changing your active feed — a new feed is applied on the next connection.
I can’t manually select a node

The Auto Sniff group is automatic by design: it continuously picks the lowest-latency node, so individual nodes in it are not manually selectable. To choose a node yourself, use the Pick a Kitty group instead.

What does the latency number after “Sniff” mean?

It depends on the state. Before connecting, Neko measures a direct TCP handshake to the node's address — a quick reachability check. While connected, it asks the kernel for the real proxied delay, which reflects what you actually experience through the tunnel.

Switching between subscriptions

Each feed keeps its own node list. In the Feeds tab, tap a feed to make it active — the Nodes tab immediately shows that feed's nodes. Use the refresh button to re-download a subscription, or the trash button to delete a feed.

Where is my data stored?

On your device only. Subscriptions, node lists and settings are saved locally in the app's own storage. Neko has no accounts and no servers of its own. See the Privacy Policy for details.
